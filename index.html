Heavy AI models (SAM, Stable Diffusion, Real-ESRGAN) cannot run locally in this browser. Configure an API endpoint below, or use the local heuristic tools which run entirely in your browser.

Background Removal Local

Analyzes edge pixels and removes contiguous background via colour-distance flood fill. Works best on solid / gradient backgrounds.

Object Select Local

Click on an object to grow a selection constrained by edge gradients (region growing).

Content-Aware Fill Local

Inpaints the active selection by diffusing surrounding pixels inward (iterative Laplace inpainting). Good for small blemishes.

Generative Fill Requires API

Prompt-based inpainting. Requires a connected backend (e.g., Stable Diffusion inpainting endpoint). It will not fabricate results locally.
